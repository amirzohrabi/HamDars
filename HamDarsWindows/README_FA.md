# هم‌درس — پروژه دسکتاپ C# و WPF

این بسته سورس پروژهٔ ویندوزی هم‌درس است؛ رابط کاربری فارسی و راست‌چین است و بخش ذخیره‌سازی محلی از طریق سرویس `LocalStore` انجام می‌شود.

## اجرای پروژه

1. در ویندوز، Visual Studio 2022 را با workload **.NET desktop development** نصب کن.
2. .NET 8 SDK را نصب داشته باش.
3. فایل `HamDars.sln` را باز کن.
4. از منوی **Build → Rebuild Solution** پروژه را بساز.
5. با کلید **F5** برنامه را اجرا کن.

## امکانات

- ثبت‌نام و ورود محلی با نام، شماره، نام کاربری، رمز و مقطع تحصیلی
- هش کردن رمز عبور با PBKDF2؛ رمز به‌صورت متن ساده در فایل ذخیره نمی‌شود
- داشبورد فارسی، برنامه‌ریزی، علامت‌زدن و حذف درس با تأیید
- تایمر تمرکز و استراحت
- آمار سادهٔ زمان، جلسه‌ها و هدف مطالعه
- ذخیرهٔ پروفایل و داده‌های برنامه به صورت JSON با نوشتن اتمی فایل‌ها
- تم تیره، فهرست‌های کشویی سفارشی و انیمیشن‌های سبک
- صفحه آغازین سینمایی با لوگوی اختصاصی، پرده‌های نئونی متحرک و امکان ردکردن با Esc
- استفاده از نماد لوگو در صفحه ورود، داشبورد و آیکون برنامه ویندوز
- هدف مطالعه روزانه تا ۱۲ ساعت

## محل نگهداری داده‌ها

برنامه فایل‌های داده را در `%LOCALAPPDATA%\HamDars` ذخیره می‌کند. این داده‌ها روی همان کامپیوتر هستند و بین دستگاه‌ها همگام‌سازی نمی‌شوند.

## نکته درباره بک‌اند

بک‌اند این بسته **محلی** است، نه سرور آنلاین. برای ثبت‌نام ابری، ورود از چند دستگاه، بازیابی حساب و همگام‌سازی، باید API سرور یا Supabase با پیکربندی و دسترسی‌های مناسب اضافه شود. اطلاعات حساس واقعی را در این نسخهٔ اولیه وارد نکن.

## خروجی EXE

برای ساخت فایل اجرایی مستقل ویندوز x64، بعد از نصب .NET 8 SDK روی ویندوز، `BUILD_WINDOWS_EXE.bat` را اجرا کن. خروجی در `publish\win-x64` ایجاد می‌شود.

برای توضیح لایه‌ها و محل ذخیره‌سازی، فایل `ARCHITECTURE_FA.md` را هم ببین. برای ساخت Debug از `BUILD_DEBUG.bat` و برای خروجی مستقل ویندوز از `BUILD_WINDOWS_EXE.bat` استفاده کن.

## وضعیت بررسی

- فایل‌های XAML با XML parser بررسی شدند و ارجاع‌های رویدادها به متدهای C# به‌صورت ایستا تطبیق داده شدند.
- محیط ساخت این بسته .NET SDK ندارد؛ بنابراین کامپایل واقعی و اجرای رابط ویندوزی در این محیط ممکن نبود.
- برای تأیید نهایی، در ویندوز **Build → Rebuild Solution** را اجرا کن. این بسته سورس کامل است، نه فایل EXE کامپایل‌شده.

## محدودهٔ بک‌اند

این نسخه یک لایهٔ ذخیره‌سازی محلی دارد؛ سرور آنلاین/API، همگام‌سازی بین دستگاه‌ها، ایمیل تأیید، بازیابی رمز و کنترل دسترسی ابری ندارد. رمزها به‌صورت متن ساده ذخیره نمی‌شوند و از PBKDF2-SHA256 با salt تصادفی استفاده می‌شود. برای استفادهٔ عمومی یا چندکاربره باید احراز هویت و دیتابیس سمت سرور جداگانه پیاده‌سازی شوند.
