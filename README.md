# 🎓 HamDars | هم‌درس

A Persian study planner built with C# and WPF.

هم‌درس یک پروژهٔ دسکتاپ برای کمک به برنامه‌ریزی درسی، مدیریت زمان مطالعه و پیگیری پیشرفت روزانه است.

## ✨ Features

- 📚 Study planning and lesson management
- ⏱️ Focus timer
- 📊 Study progress tracking
- 💜 Modern interface with a purple and blue theme
- 🎬 Animated startup screen

## 🛠️ Built With

- C#
- WPF
- .NET

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `HamDars.sln` in Visual Studio.
3. Restore the required dependencies.
4. Build and run the project.
